# Проект: анализ данных Airbnb (ML/DLOps)

Домашнее задание № 1 к семинару по ML/DLOps: чтение CSV-файла из S3-хранилища Yandex Cloud с резервным чтением локальной копии.

## Источник данных

- Хранилище: Yandex Object Storage (S3-совместимое).
- Бакет: `mlops26-course-bucket`.
- Ключ объекта: `prepared/train.csv`.
- Локальная копия: `data/train.csv`.

## Содержимое проекта

- `01_read_data.ipynb` — ноутбук с функциями `read_s3_csv()` и `read_data()` и проверками их работы.
- `README.md` — описание и инструкция по запуску.
- `.gitignore` — исключение локальных данных, ключей и служебных файлов из Git.

## Как открыть и запустить ноутбук

Ноутбук можно открыть в **Google Colab** или локально в **JupyterLab**. Установите необходимые библиотеки:

```bash
pip install boto3 pandas jupyterlab
```

Для локального запуска выполните `jupyter lab` в папке проекта, затем откройте `01_read_data.ipynb`. В Google Colab откройте ноутбук и выполните установочную ячейку, если библиотека `boto3` ещё не установлена.

Создайте **только у себя** файл `secretkeys.py` рядом с ноутбуком со следующими переменными (подставьте выданные преподавателем значения):

```python
KEY_ID = "<ваш идентификатор ключа>"
ACCESS_KEY = "<ваш секретный ключ>"
```

Файл `secretkeys.py` не загружается в GitHub. В Colab его нужно загрузить в корневую папку текущей сессии отдельно от ноутбука.

Для проверки резервного чтения сохраните копию исходного CSV по пути `data/train.csv`. Папка `data/` тоже не входит в репозиторий. Затем запустите ячейки ноутбука сверху вниз:

1. `read_s3_csv()` получает объект из S3 и возвращает таблицу `pandas.DataFrame`.
2. `read_data()` сначала обращается к S3; при ошибке сети или доступа использует локальный CSV, если указан путь к нему.
3. Контрольная ячейка с намеренно неверным S3-ключом проверяет переход к локальному файлу.

**Безопасность:** не публикуйте ключи доступа, `secretkeys.py`, локальные CSV или вывод ячеек с конфиденциальными данными.
