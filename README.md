# Проект: анализ данных Airbnb (ML/DLOps)

Домашнее задание № 1 к семинару по ML/DLOps — чтение CSV-файла из S3-хранилища Yandex Cloud с возможностью перехода к локальной копии.

## Источник данных

- Хранилище: Yandex Object Storage (S3-совместимое).
- Бакет: `mlops26-course-bucket`.
- Ключ объекта: `prepared/train.csv`.
- Локальная копия: `data/train.csv`.

## Содержимое проекта

- `01_read_data.ipynb` — ноутбук с функциями чтения данных и проверками их работы.
- `README.md` — описание проекта и инструкция по запуску.
- `.gitignore` — исключение локальных данных, ключей доступа и служебных файлов из Git.

## Запуск ноутбука

1. Откройте `01_read_data.ipynb` в Google Colab или JupyterLab.
2. Для подключения к S3 используйте локальный файл `secretkeys.py`, содержащий переменные:
   - `KEY_ID` — идентификатор ключа доступа;
   - `ACCESS_KEY` — секретный ключ доступа.
3. В Google Colab загрузите `secretkeys.py` в рабочую папку текущей сессии.
4. Запустите ячейки ноутбука последовательно сверху вниз.

Локальная копия `data/train.csv` скачивается из S3 непосредственно в ноутбуке.

## Реализованные функции

- `read_s3_csv(bucket, key)` — читает CSV из S3 и возвращает `pandas.DataFrame`.
- `read_data(bucket, key, local_path=None)` — сначала обращается к S3, а при ошибке доступа использует локальный CSV, если указан путь.

В ноутбуке проверяются обычное чтение данных и переход к локальной копии при использовании неверного ключа объекта.

## Безопасность

Файл `secretkeys.py` и папка `data/` исключены из Git с помощью `.gitignore` и не загружаются в репозиторий.
